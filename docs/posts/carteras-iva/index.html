1. Business Context & Goals

Credit investors often buy non‑performing loan portfolios at a discount. To make informed decisions, they need to:

  • Estimate the Present Value (PV) of future loan cash flows.
  • Calculate IVA recovery on interest payments.
  • Model the impact of default rates (mora) on actual returns.

Goal: Build a Shiny tool that accepts portfolio parameters and outputs:

  • Amortization schedule with IVA breakdown
  • Purchase price (NPV) and key metrics (IRR, payback, duration)
  • Interactive visualizations for performance analysis

6.2 Automated Tests

library(testthat)
test_that("PV calculation matches Excel", {
  f <- rep(100, 12)
  expect_equal(a_npv(f, r = 0.01), 100 * (1 - (1 + 0.01)^(-12)) / 0.01)
})

Why: Ensures that future changes don’t break critical financial logic.
