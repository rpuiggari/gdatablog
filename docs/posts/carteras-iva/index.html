1 Summary

I’ve developed an interactive R Shiny application that analyzes the performance of loan portfolios, providing comprehensive financial metrics and visualizations for investment decision-making. The tool calculates key performance indicators including ROI, IRR, payback periods, and tax implications, making it invaluable for portfolio managers and financial analysts.

Try the live application | View source code on GitHub

Key Features:

  • Interactive amortization calculations with French payment system

  • Dual input modes: Capital amount or target tax recovery

  • Real-time financial metrics including ROI, IRR, and payback analysis

  • Advanced visualizations showing component breakdown and cumulative cash flows

  • Tax optimization with IVA calculations and purchase tax implications

  • Responsive design with modern UI/UX using Bootstrap themes

2 Why This Tool Matters

Portfolio performance analysis is crucial for making informed investment decisions in the financial sector. This application addresses several key challenges:

  1. Standardized Analysis: Provides consistent methodology for evaluating different portfolio opportunities

  2. Tax Optimization: Incorporates complex tax calculations (IVA) that significantly impact returns

  3. Risk Assessment: Includes delinquency rate modeling to assess realistic performance scenarios

  4. Decision Support: Delivers actionable insights through interactive visualizations

3.2 Key Performance Indicators

The calc_kpis() function computes essential metrics:

  • Net Present Value (NPV): Using constant cash flows for valuation

  • Internal Rate of Return (IRR): Calculated through numerical optimization

  • Payback Period: Time to recover initial investment

  • Duration: Weighted average time to cash flow recovery

  • ROI Ratios: Multiple return calculations with tax considerations

3.3 Advanced Features

Dual Input Modes:

  • Capital Mode: Start with portfolio value, calculate expected returns

  • Tax Recovery Mode: Reverse-engineer required capital from target tax benefits
